## 🌟 مميزات الموقع
1. **تصميم متجاوب بالكامل (Fully Responsive):** يرتكز على إطار عمل Tailwind CSS ويعمل بسلاسة فائقة على الجوالات، الآيفون، الأجهزة اللوحية والكمبيوتر.
2. **تحسين محركات البحث (SEO Optimized):** مجهز بكافة الكلمات المفتاحية الرئيسية والأوسمة المناسبة للتصدر في نتائج البحث (مثل: مقاول حفر، مقاول ترحيل، مقاول دفان، مقاول أسفلت، بوكلين، شيول، إلخ).
3. **ألوان متناسقة وفخمة:** ألوان معتمدة لصناعة المقاولات (الأسود، الأصفر الصناعي/الذهبي، الرمادي الداكن والأبيض).
4. **أزرار تواصل عائمة ومباشرة:** زر اتصال مباشر وزر واتساب ثابتين في الشاشة للوصول السريع.
5. **معرض صور تفاعلي (Lightbox Gallery):** يتضمن الصور المرفقة لمواقع العمل مع إمكانية التكبير والتصفح.
6. **نموذج طلب عرض سعر تفاعلي:** يتيح للعملاء إرسال بيانات المشروع والحصول على تسعيرة مباشرة.

## 🚀 كيفية رفع الموقع واستضافته مجانًا عبر GitHub Pages

1. **إنشاء مستودع جديد (Repository) على GitHub:**
   - قم بالدخول إلى حسابك على GitHub واضغط على **New Repository**.
   - اختر اسماً للمستودع (مثلاً: `excavation-contractor-riyadh`).
   - اجعل المستودع **Public**.

2. **رفع الملفات:**
   - قم برفع ملف `index.html` وملف `README.md` وجميع الصور المرفقة (`image.png` إلى `image_10.png`) بنفس أسمائها الحالية تماماً.

3. **تفعيل خدمة GitHub Pages:**
   - اذهب إلى **Settings** الخاصة بالمستودع على GitHub.
   - من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment** اختر الفرع الرئيسي `main` أو `master` ثم اضغط **Save**.
   - سيتم نشر موقعك مجاناً خلال دقائق وسيصبح متاحاً على رابط مثل:
     `https://yourusername.github.io/excavation-contractor-riyadh/`
